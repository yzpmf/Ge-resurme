项目简介

LifeOS 是我用 React Native / Expo 独立开发的一款个人生活管理 App。 它把日常需要的几件事——待办规划、上课安排、习惯打卡——收拢到一处， 再用一个接入大模型的 AI 助手把它们串起来：你只管用自然语言说，剩下的归类、提醒和记录交给它。 所有数据都存在手机本地，不上传任何服务器。

核心功能

五个模块，覆盖一天的安排

四象限待办

按 DDL 自动归类「短期 / 长期」，你只需标紧急；标记后即进入「马上做」，逾期一目了然。

本周计划

仿「七天计划」的最小行动清单，把长期目标拆成这一周能推进的一小步。

课程表

单双周课程管理，支持临时调课，还能用 AI 直接截图导入整张课表。

每日打卡

自定义习惯与提醒，近 7 天热力图直观看坚持情况。

AI 助手

接入任意 OpenAI 兼容大模型，自然语言查日程、销账、创建任务、完成打卡。

本地存储

任务、课程、习惯与设置全部存在本地，隐私无忧，离线可用。

技术栈

React Native Expo JavaScript AsyncStorage Expo Notifications 大模型 API（OpenAI 兼容）
